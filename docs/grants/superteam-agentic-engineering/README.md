# Superteam Agentic Engineering Grant Kit

This folder contains a complete submission package for the Superteam Agentic Engineering grant.

## Files

- `01-application-form.md` - Full long-form application answers
- `02-one-pager.md` - One-page project summary
- `03-milestones-and-budget.md` - Execution plan, timeline, and budget
- `04-proof-and-links.md` - On-chain proof links, product links, and evidence
- `05-demo-script.md` - 3-5 minute demo narration script
- `06-upload-checklist.md` - Google Drive packaging and upload checklist

## How to use

1. Open `01-application-form.md` and adapt any fields that require personal details (name, email, team wallet, etc.).
2. Record a short demo using `05-demo-script.md`.
3. Put exported PDFs/assets in one Drive folder and follow `06-upload-checklist.md`.
